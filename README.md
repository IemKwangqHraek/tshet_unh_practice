# 切韻練字

中古漢語全拼／三拼練習網站，採用已確認的 prengQvm 小改版與「古今混合頻率優化 v1」鍵位。名稱中的「韻」採《廣韻》云合三C文去：`unh`／`DFC`；云合三B真去另作 `ryinh`／`DNC`。

## 本機使用

需要 Node.js 22.12 以上版本。

```sh
npm ci --ignore-scripts
npm run dev
```

開啟 `http://127.0.0.1:5177/`。正式版可用 `npm run build` 生成 `dist/`，再執行 `npm run preview`（預覽網址為 `http://127.0.0.1:5178/`）；也可將 `dist/` 放在靜態 HTTP 伺服器。本站不需要後端或 Rime 安裝。

## 功能

- 全拼逐字輸入，以 Space 確認；三拼固定三鍵後確認。錯鍵保留，按 Backspace 退格重試，Esc 暫停／恢復。
- 三拼鍵帽支援 QWERTY、全信息有／無高亮、當前 Key 有／無高亮。當前 Key 根據已輸入前綴，篩選完整合法音節中的候選片段；共鍵片段不會被提前消歧。
- 音韻地位、全拼答案、三段拆分可獨立關閉。鍵帽支援滑鼠／觸控輸入。
- 導入 UTF-8 TXT、TSV、JSON，可拖入文件或貼入文本。原文、標點、換行、原始標註與選讀校對記錄均保存。
- 多讀、缺失、無效標註、字典未收讀音有分別的校對狀態。可手動填寫音韻地位、選擇建議讀音、確認保留字典未收讀音，或跳過該字。
- 語料、提示設定、最近 50 次成績及未完成的練習進度保存在本機瀏覽器。重載／切換頁面後未完成練習暫停，需手動繼續。
- 結果顯示字／分、字母按鍵正確率、有效用時、K1／K2／K3 錯鍵分佈，並可生成錯字複習。
- 保留《王孫遊》《春曉》《相思》三篇初始範例；內建語料庫提供 852 個篇章／段落條目，503 個可直接練習。支援搜尋標題、作者、正文，按類別與讀音狀態篩選，按篇加入本機語料。
- polyhedron《唐詩三百首》303 個編號條目與《論語》533 段已轉成音韻地位；另收錄 9 首逐字標註宋詞。原始拼音、來源版本及待校對記錄隨 JSON 匯出。

語料與成績以網址來源區分：開發伺服器與正式部署網址會使用不同的瀏覽器儲存。清除網站資料或換瀏覽器前，請匯出語料備份。輸入時請切換至英文鍵盤；輸入法組字與貼上不計入練習。

## 導入與資料來源

見 [導入格式](docs/import-formats.md)、[資料來源](docs/sources.md) 與 [語料轉換說明](docs/corpus-conversion.md)。polyhedron 原文／拼音分行格式可直接導入；音節數不一致時會停止該次導入。純拼音《唐詩三百首》使用內建的原文配對版本。非唯一映射、字典未收及原作者疑讀仍需校對。

重建固定版本語料（首次會下載並核對來源 SHA-256）：

```sh
npm run build:corpora
npm run check:corpora
```

## 驗證

```sh
npm test
npm run build
```

測試包含 3,809 個固定音節與鍵表一致性、兩個「韻」讀音、前綴候選篩選、四種導入格式、Unicode 索引、校對／匯出重讀、錯鍵退格、全拼空格確認、暫停計時、提示關閉與本機儲存失敗處理，並逐條核對全部內建語料的狀態、原拼音回推及來源資訊保留。瀏覽器驗收見 [驗收記錄](docs/verification.md)。

這是一個獨立 Git 倉庫；拼音方案、鍵表與資料快照已包含在專案內，執行時不依賴外層 TU3K 倉庫。
