# 驗收記錄

驗證日期：2026-10-02。執行環境：Windows、Node.js 24.17.0、Codex 內建 Chromium 瀏覽器。

## 資料與單元測試

`npm test` 的 10 項測試通過，其中逐一比對 3,809 個固定音節的全拼、三段、三拼與鍵位映射。測試亦覆蓋前綴候選、TXT／TSV／JSON、非 BMP 字元、校對記錄匯出重讀、字典未收讀音、錯鍵退格、全拼確認、暫停計時、提示關閉及儲存失敗。

以完整 nk2028 語料執行新導入器：19 篇，去除標題與作者後正文 2,934 個漢字。31 個字與指定音韻地位的組合未收於固定字庫，均保留並列入待校對；沒有缺失、無效或推導失敗的標註。

## 瀏覽器操作

- 《春曉》完整三拼 20 字：在 K2 人為輸錯一次，未退格時後續輸入被阻擋；退格後可繼續，結果為 60 次正確／61 次字母按鍵，98.4%，K2 錯誤 1 次。
- 從結果生成「春」的單字錯字複習：輸入第一鍵後重載，原鍵與進度保留，練習自動暫停；繼續後完成，3／3 字母按鍵正確。
- Esc 連續暫停／恢復：暫停重繪使焦點移出輸入框後，仍可再次按 Esc 恢復練習。
- 「校對範例」：導入「聞」的兩種讀音、「曉」缺失標註、「抬」字典未收標註；分別選讀、補填與確認保留。無效的手動地位被拒絕，成功校對後待處理數降至 0。
- 上述語料轉為全拼後，第一字保留人工選擇的 `munh`，完整音節不會在按 Space 前前進。人為輸錯一次後，三字完成結果為 11／12，91.7%。
- 五種鍵帽模式：高亮模式各有一個目標鍵，三種無高亮模式沒有高亮。K2 在前綴 Q 下，U 僅有 wa，J 保留 wu／yi；選 K3 後前綴更新為 QK。
- 經實際文件選擇器載入 `public/example.tsv`，識別正文「韻，切」，2 字，讀音均有效。
- 390 × 844 窄螢幕：練習與導入頁面沒有橫向溢出；20 列校對表格在獨立容器橫向捲動，頁面本身不溢出。驗證後已撤銷尺寸覆寫。

## 建置與範圍

`npm run build` 通過，`npm run preview` 使用 `127.0.0.1:5178` 提供正式建置。本網站未部署至外部服務，沒有添加 Git 遠端，也沒有修改使用者的 Rime 配置。

瀏覽器開發驗收使用 5177，正式建置預覽使用獨立來源 5178，避免將驗收過程中的練習記錄混入初次使用資料。

## 語料擴充驗收

同日新增 polyhedron 轉換、固定來源重建與語料目錄後，`npm test` 的 16 項測試全部通過。新增測試覆蓋拼音反查、多讀及編輯疑讀、漢字與音節數不一致、非 BMP 字元、原始拼音與來源資訊匯出重讀，以及全部目錄條目的狀態與確定讀音重推導。`npm run check:corpora` 確認固定來源可重建出完全一致的資料，`npm run build` 與 `git diff --check` 通過。
