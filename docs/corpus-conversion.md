## 確定性與保留事項

1. 用固定版本古韻羅馬字推導，對 `tshet-uinh 0.15.4` 的音韻地位建立反向索引。原文中的字與原拼音共同限定候選，不經現代普通話拼音中轉。
2. 優先取該字在字庫中且拼音完全相同的地位。只有原音單一、候選地位單一時才直接可練。`pyot` 會保留《論語》的「不」入聲選讀，不會被初始《春曉》範例的上聲覆蓋。
3. 多個地位、斜線多讀、原作者疑讀保留候選與原音，須校對。若字库没有此字與原音的組合，只提供整體反向索引候選，不自動確認；`???` 保留缺讀。
4. 《論語》原文與拼音逐段核對字數；533 段中原有 14 段失配，現已逐段定位漏音、多音與括注，恢復可靠配對；13 處實缺音與「文」的兩讀保留，原拼音及配對校訂可在「語料資料」查看。一般自選導入仍拒絕字數失配，不擴大套用這些指定詞例規則。
5. 唐詩以作者、逐字拼音相容度與漢字數識別原文；老版本專名讀音不相容時，只接受正文至少 90% 相容的完整候選。全篇通常接受字庫相容度至少 80% 的原文候選，未匹配的字不自動確認。近似原文只在同作者、同字數、至少 85% 漢字相同時視為同一作品的版本候選；按拼音相容度選取完整版本，並要求不新增原本不存在的字音衝突；來源、原正文、逐字差異、組詩分段範圍及其他版本保存為證據。這是文本識別與標註轉換，並非宣稱異文或每一处選讀已完成人工訓詁校勘。
6. 唐詩第 23 號《賊退示官吏並序》只轉換詩歌正文；序的拼音另存 `excludedPrefaceRomanization`，標題明示「正文」。没有凭不同版本的序強行逐字配對。
7. 文本、原標註、原拼音、源提交、許可、人工校對記錄均随 JSON 匯出及重讀保留。polyhedron 衍生標註維持 CC BY-NC-SA 3.0，與其他 CC0 資料逐篇區分。

## 《詩經》全書標註初稿

本輪新增確認 1,348 字位並修正 3 處右字選讀，正文與完整原拼音保留；詳見 [確認記錄](corpus-confirmation-review.md)。更新後分類覆蓋四包全部 931 個待核字位，區分文獻多說與現行配對、字形、詞義等卡點。詳見 [分類與優先次序](pending-classification.md)、[逐字完整分類](pending-classification.json)；可用 `npm run classify:pending` 重建分類，`npm run check:pending` 檢查其與當前語料及固定引文一致。

全書 305 篇，正文 29,646 字，保持 rime-aca 固定版本的原字、標點和換行。十五國風、74 篇小雅、31 篇大雅、31 篇周頌、4 篇魯頌、5 篇商頌都已入庫；六篇只有篇名的笙詩不另造正文。`sequenceNumber` 是本語料的 1–305 順序號，不是包含笙詩篇名的毛詩篇號。小雅、大雅、周頌標題保留「之什」分組。

28,995 字已有選定地位（約 97.8%），118 篇可直接練習，187 篇仍有 651 處待核。這是切韻系練習讀法的標註初稿，尚未完成全書逐字訓詁校定。完整待核清單及各選讀方法的字數由 [shijing-review.json](shijing-review.json) 生成，包含每篇的字位、上下文、候選、原因及古注。字位為不含標點的零起始索引；網站顯示時加一。

音義基底為 Kanripo 四部叢刊本《詩集傳》二十卷，另以《經典釋文》毛詩音義補證。配對先排除小字古注、版面標記，只作已列異體對應及 Unicode 相容字正規化；不改練習正文。每字取相鄰 11 字（最少 8 字）尋找古注底文，篇首尾向內延長窗口。缺頁、異文或多處音值不同時不強行跨缺漏配對。頁碼和實際配對上下文隨證據保存。

初列直音、反切須推出唯一地位才採用；反切優先核對該字字庫原切，再以切上聲母、切下韻調和等呼限制該字候選。音注中的已列異體字如戸／戶、遥／遙、吕／呂只在查字時歸一，原引文照存。脣音在字庫中不標開合，不能用這個空值排除另一字相同韻、聲、等的讀音；若放寬後仍有兩個地位，繼續待核。重紐類別由該字已有候選限制。只解析首列常音，`叶`、`協`提示不參與推導；「音又」或反切用字中的又仍屬音注本體。本輪核到明列另讀的待核字位另外保留，不讓首音自動確認蓋過。宋人或早期音注不能在固定切韻字庫中唯一互證時，保留原注，不能僅憑反切拼成不合法的地位。

多讀詞按 `scripts/shijing-lexical.json` 的明示字義規則選讀；詞組規則優先，例如參差、委蛇、朝夕，以及予作給與的用法。同義異讀亦列出本版的選擇，不宣稱只有一讀。每條規則均驗證地位、反切及《廣韻》釋義。異體、缺字和借音的補讀列在 `scripts/shijing-supplements.json`，同音參照字不冒充原字釋義；其中明示引文的補讀另驗證卷、頁及引文。音注未能互證而採詞義規則時，依據中並列原音注和比較說明。

前一輪檢索補入 `scripts/shijing-researched.json` 的 28 條規則，依具體篇名與詞例限制適用範圍，並核對卷頁、音注引文和所附底文詞頭。例如太王的大不會套用於〈文王有聲〉的大王；〈抑〉克共明刑取上聲，與〈小明〉共人取平聲分開。前一輪共減少 202 處待核，並按古注修正 17 處既有選讀。檢索結果見 [shijing-research.md](shijing-research.md)，逐項變更與原候選見 [shijing-research.json](shijing-research.json)。

已有〈芣苢〉〈桃夭〉保留原 ID 和試點讀音：Shijing-net XML 詩句仍須與固定正文及已審查序列完全一致，並按 XML ID 核對陸德明引文。〈桃夭〉華音花的維基文庫引文繼續固定於原修訂，沒有擴大使用該轉錄的其他音注。

本次語義覆核新增 `scripts/shijing-semantic.json` 的 181 個指定字位選讀：178 處原先未選讀，3 處既有讀音修正。每個詞例同時限定篇名、零起始漢字索引與前後正文；完整《王三》《廣韻》來源在重建時核驗 SHA-256，引用再核對條目號、字頭、反切、地位與完整釋義。20 處新增讀音有本篇明列音注；其餘 158 處是本版語境採讀，不將同義異讀當成已排除。兩韻書對同一義項列有不同讀音時，以本篇古注或明示的版本選讀處理，不能套用動平名去規則。詳見 [shijing-semantic-review.json](shijing-semantic-review.json)。

所有字庫候選保存在 `positions`，選讀保存在 `position`；字庫未收的補讀須有編校記錄並標為已確認。`audit`、`provenance.readingNotes` 保存字位、選讀、引文、頁碼、版本及依據，`pendingReadings` 保存未決項；不跳字，也不取字典第一項填平多讀。網站「語料資料」可展開這兩類依據，JSON 匯出重讀保留全部記錄。

全書包在 `public/corpora/shijing.json`，按篇懶載入到本機。「詩經」篩選下可按 20 個國風／雅頌分部下載 22 個 JSON（小雅、大雅各分兩檔；完整檔名見 `public/corpora/shijing-downloads.json`），每包小於單次導入上限，合計恰好 305 篇且不重複。完整大包用於程式載入，不直接貼入有 2 MB 上限的導入框。

## 重建與驗證

```sh
npm run build:corpora
npm run check:corpora
npm test
npm run build
```

本輪《論語注疏》二十卷原文另固定在 `scripts/snapshots/analects-commentary.json`，含來源提交與逐檔 SHA-256。來源提交、URL 與 SHA-256 固定在 `scripts/corpus-sources.json`；新增唐詩完整正文快照另固定於 `scripts/corpus-edition-sources.json`，原始快取在已忽略的 `.cache/corpus-sources/`。推導函數是已檢查的本地 CC0 快照；重建不執行下載的程式碼。資料包在 `public/corpora/`，搜尋索引在 `src/data/catalogue.json`。驗證覆蓋全庫狀態、可靠轉換的原拼音回推、缺漏、疑讀、非 BMP 字、來源與校對記錄的匯出重讀。
