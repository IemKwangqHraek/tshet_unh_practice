## 確定性與保留事項

1. 用固定版本古韻羅馬字推導，對 `tshet-uinh 0.15.4` 的音韻地位建立反向索引。原文中的字與原拼音共同限定候選，不經現代普通話拼音中轉。
2. 優先取該字在字庫中且拼音完全相同的地位。只有原音單一、候選地位單一時才直接可練。`pyot` 會保留《論語》的「不」入聲選讀，不會被初始《春曉》範例的上聲覆蓋。
3. 多個地位、斜線多讀、原作者疑讀保留候選與原音，須校對。若字库没有此字與原音的組合，只提供整體反向索引候選，不自動確認；`???` 保留缺讀。
4. 《論語》原文與拼音逐段核對字數；533 段中 14 段不一致，整段漢字保留缺失標註，原拼音與错误說明可在「語料資料」查看。沒有在一處缺漏後繼續錯位配對。
5. 唐詩以作者、逐字拼音相容度與漢字數識別原文；老版本專名讀音不相容時，只接受正文至少 90% 相容的完整候選。全篇通常接受字庫相容度至少 80% 的原文候選，未匹配的字不自動確認。近似原文只在同作者、同字數、至少 85% 漢字相同時視為同一作品的版本候選；按最高拼音相容度選取，來源與分數保存為證據。這是文本識別與標註轉換，並非宣稱異文或每一处選讀已完成人工訓詁校勘。
6. 唐詩第 23 號《賊退示官吏並序》只轉換詩歌正文；序的拼音另存 `excludedPrefaceRomanization`，標題明示「正文」。没有凭不同版本的序強行逐字配對。
7. 文本、原標註、原拼音、源提交、許可、人工校對記錄均随 JSON 匯出及重讀保留。polyhedron 衍生標註維持 CC BY-NC-SA 3.0，與其他 CC0 資料逐篇區分。

## 其他經典詩歌的搜尋結果

- **宋詞：已找到逐字音韻地位標註。** [nk2028/tshet-uinh-text-label](https://github.com/nk2028/tshet-uinh-text-label) 收錄《蘇幕遮》《滿江紅》《念奴嬌·過洞庭》《青玉案·元夕》《秋霽》《惜黃花慢》《慶宮春·水仙花》《柳梢青·春感》《虞美人》。已接入。
- **樂府：已接入唐詩選本中的樂府。** 如《遊子吟》《關山月》《將進酒》等，使用 polyhedron 的原注音。這不代表已收齊漢樂府或南北朝民歌。
- **詩經、楚辭：本次未找到可直接批量轉換、選讀已確定且可追溯的逐字中古音標註。** [rime-aca/corpus](https://github.com/rime-aca/corpus) 有正文，[漢籍リポジトリ《楚辭章句》](https://github.com/kanripo/KR4a0002) 有古注，但不能當成已有逐字中古注音。古注反切可作下一批人工校對的依據。
- **南北朝民歌：找到 polyhedron《敕勒歌》《木蘭辭》的朗讀索引。** 見 [韻典網中古漢語韻文朗讀](https://ytenx.org/byohlyuk/YonhMyon)。本次沒有取得可核對的逐字文字注音，因此未從音訊猜讀或宣稱已收錄。
- [poem_auto_tag](https://github.com/laubonghaudoi/poem_auto_tag) 是自動候選標註工具，輸出仍可能多讀；本次没有把自動產生的讀音當作已有人工注音。

網站練習目標是切韻音系。即使將來加入《詩經》《楚辭》，所標也應明示為切韻系讀法；上古擬音與切韻音韻地位不能直接當作同一套標註。

## 重建與驗證

```sh
npm run build:corpora
npm run check:corpora
npm test
npm run build
```

來源提交、URL 與 SHA-256 固定在 `scripts/corpus-sources.json`，原始快取在已忽略的 `.cache/corpus-sources/`。推導函數是已檢查的本地 CC0 快照；重建不執行下載的程式碼。資料包在 `public/corpora/`，搜尋索引在 `src/data/catalogue.json`。驗證覆蓋全庫狀態、可靠轉換的原拼音回推、缺漏、疑讀、非 BMP 字、來源與校對記錄的匯出重讀。
